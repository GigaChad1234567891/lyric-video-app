LYRIC VIDEO - APP THAT UPDATES ITSELF

This is a web app you host for free on GitHub Pages and then install on your phone
and Windows laptop. Whenever you replace index.html on GitHub, the installed app
loads the new version the next time you open it with internet.

PART 1 - PUT IT ONLINE (once)
1. On github.com click + > New repository. Name it  lyric-video-app  and choose PUBLIC
   (free Pages sites need a public repository).
2. Click "uploading an existing file" and drag in EVERYTHING in this folder
   (index.html, sw.js, manifest.webmanifest, both icon files). Click Commit changes.
3. Go to Settings > Pages. Under Branch pick  main  and  / (root), then Save.
4. Wait 1 to 2 minutes and refresh. Your link appears at the top:
   https://YOUR-NAME.github.io/lyric-video-app/

PART 2 - INSTALL IT
- Android: open the link in Chrome, tap the 3 dots, then Install app (or Add to Home screen).
- Windows: open the link in Chrome or Edge and click the install icon on the right of the address bar.

PART 3 - UPDATE IT LATER
Open your repository, click index.html, click the pencil/Upload files option to replace it
with the new file (named index.html), and Commit changes. Wait 1 to 2 minutes.
Next time you open the installed app with internet, it shows the new version.

Note: anyone with your link can open the page, and the song clip is inside it.
